Native visual scenes are declared in `scenes/*.json` and compiled into the native registry by the crate build script. References are IDs resolved by the visual runner; the manifest contains no external filesystem paths. `python3 -B ci/visual/scenes.py check ci/visual/scenes/g1-01.json` checks the registered IDs, settings and reference provenance.

The `flea` IPC registry adds `scene(window, name, settings)`, `nativeGeometry(window, scene, frame)`, `pendingRequests`, `previewReadiness`, `sceneState` and `presentedFrame`. The window argument is the decimal process ID, and settings is JSON containing an absolute fixture `path`, optional integer `width` and `height`. Each manifest scene names its own `cursor`, `selection`, `text_size`, `density`, `reduced_motion` and `caret_blink`, and the window applies them to the focused pane before it builds the frame that earns the receipt. The receipt reports what that frame drew: the cursor the rows were laid out with, the size the rows were shaped at and the density of the drawn row height. The window can honour Compact density only, rows at 14 and no caret animation today: a scene asking for another density or a caret is refused, and one asking for a text size the rows do not draw is never presented and expires. The caller sets the compositor client dimensions and rounding before requesting a scene.

A scene reply is deferred until its complete backend snapshot has passed through the native render and present submission path. Its receipt carries the scene, process, frame, client dimensions and scale. The native next-frame callback observes the preceding submission; this is not compositor presentation feedback. An unmatched client size or a snapshot that never renders expires after 1500 ms with status 2. Unknown scenes, another window and unavailable geometry also return status 2. A second scene while requests remain pending is refused.

Geometry is recorded on demand during native prepaint, only for visible rows and drawn host surfaces. Logical rectangles describe layout; clipped pixel rectangles stay inside the viewport. The sidecar contains the exact displayed text retained with the shaped row. `scenes.py wrapper` validates receipt identity and required roles, hashes the unchanged PNG and creates tagged HTML using only these exported rectangles. The existing geometry probe can inspect that HTML without deriving coordinates from reference boards or pixels.

The native scene suite shares the capture smoke's private headless Hyprland session. It uses the owned-window transport and the staged `flea --gui` launcher, checks stable bytes one second apart, client and output scale, black pixels and geometry, and exercises unknown-scene, wrong-window, never-presented and empty-sidecar refusals. The smoke separately retains Vulkan and GL software-renderer checks.

The current host draws the listing element in Columns and Grid slots as well as List, and starts the second list lazily in Dual. Capturing those scenes does not establish completion of their view-specific drawing or theme fidelity. Cross-renderer comparison requires native pixel review before a baseline is approved.
