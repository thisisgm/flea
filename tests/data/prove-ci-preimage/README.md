These four minimal synthetic preimages exercise the external CI patch preparer. They contain no copied operational configuration or host policy. Replacement targets retain the expected function boundaries and every exact transform anchor. The image identity and tool verdict functions are the required preserved contracts.

SHA256SUMS pins these inputs. The suite prepares the actual patch, applies it with zero fuzz inside its marked sandbox, compares every candidate byte, checks shell syntax and staging order, and executes functions extracted from the produced candidate. Old dispatch entries are intentional inputs for replacement and drift rejection.

The fixture is a transform contract, not a runnable deployment. Preparing a patch does not install it or rebuild an image.
