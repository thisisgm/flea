# Theme golden table

`tests/fixtures/theme-golden.tsv` uses frozen Flea v0.3.12 `ui/` and live Omarchy Commons. It covers the 23 current stock palettes, with Osaka Jade replaced by Jade Horse and Starship included. Jade Horse and Starship were generated with this exporter from CI image `6a8df67c49bb` (Omarchy tree digest `2b04c259704d`); the missing read-only color helper came from the verified `omarchy-4.5.0rc2-1` edge package. Other rows retain the original minipc export from Omarchy commit `bf9ee5c` verbatim. Every case includes its palette and shell inputs, so the Rust test needs no installed themes.

On the controller's Omarchy machine, run:

```sh
tools/theme-golden/run.sh /absolute/omarchy/shell /absolute/frozen-v0.3.12/ui /absolute/installed/palettes > candidate.tsv
```

Each palette directory must contain `colors.toml`. A supplied `shell.toml` wins; otherwise the probe renders Omarchy's shell template using its read-only `omarchy-theme-color --all` resolver, then applies `shell.<section>.toml` overrides. An unknown template function fails explicitly. Pass additional disjoint roots to include user palettes. This runs one Quickshell process with read-only links to Commons and frozen Flea QML. Its HOME, config, state, cache, generated manifest and logs live under a fresh marked `.superpowers/g05/golden.*` directory. It does not set the desktop theme or rewrite user settings. The runner publishes TSV only after the completion sentinel and both-stop coverage pass. Review the candidate, retain only palettes shipped with Omarchy, replace the fixture and run `test --locked -p flea --lib -- theme` through the host broker.

The scratch UI state follows the system text size through frozen `ViewState.setTextSize`; its derived `textSize` property is read-only. Startup, palette steps and deferred dump callbacks catch exceptions, print `THEME_GOLDEN_FAIL` and terminate qs immediately. The runner rejects that marker and logged JavaScript errors. Exit 124 is an explicit timeout failure; otherwise a valid completed dump succeeds independently of the status from qs terminating itself.

Rows are `palette`, `stop`, `token`, `value`, separated by literal tabs. Input keys include a six-digit ordinal, such as `input.colors.000000.accent`, preserving Commons source order when the Rust test reconstructs the files. Colors are normalized to `#AARRGGBB`; scalar control numbers have six decimals. The 114 resolved tokens per case include all ThemeColors fields, Commons font and spacing tokens, control fills and frames, the four control border widths, and the cursor and tag treatments. Control numbers follow Commons' finite `Number` coercion, including whitespace-only zero and Qt's signed 64-bit conversion after radix prefixes. Widths round and clamp to zero, with normal feeding hover and hover feeding focus; selected defaults independently to zero. Decorations use the deterministic baseline of radius 0, gaps 5 and motion enabled. The GUI supplies live Hyprland values through `Decoration`; those compositor values are not palette goldens. Concrete font resolution also belongs to the caller's background `fc-match` task, as in Commons, while the token family remains `monospace`.

The only deliberate derivation changes from the frozen QML are the approved marked-row contrast easing and the 2026-10-17 tag fallback rule. The Gray tag may be gray. Other tag colors below raw RGB saturation 0.12 require digits, as do missing or duplicate raw colors. No hue window is used. The swatch is 14 px and its colors clear 3:1 on the listing and menu grounds.

Run `python3 tools/theme-golden/check.py` for a local parse/load check of the complete exporter against minimal module stubs. It also exercises channel conversion and the retained tag rule at raw saturation 0.12, just below that boundary, at black, with a missing color and with a duplicate color. This is a lightweight exporter regression check; agreement with real Commons still comes from the controller's QML export. Accent and urgent classification use QColor's quantized float HSV saturation, while tag classification uses the frozen helper's raw RGB arithmetic. Spacing follows Commons' `parseFloat` prefix semantics independently of control alpha parsing.

Run `python3 tools/theme-golden/check-runner.py` to exercise completion, errors and timeout handling with a deterministic qs stand-in. It does not verify QML token values.

`ThemePaths::load` and `ThemeWatcher::poll` belong on a background thread. Polling compares paths, targets, inode identity, length, mtimes and ctimes, so replacing a theme directory does not lose the subscription. A changed fontconfig stamp asks the caller to rerun `fc-match`; a theme change or Hyprland `configreloaded` asks it to reread decoration options. No compositor or subprocess work happens on a paint path. `Material` exposes the frozen glass ink lift separately; the table describes the default opaque palette.
